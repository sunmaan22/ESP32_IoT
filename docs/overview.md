# 프로젝트 개요

> 제출 문서(개발 목표·기술 개요·기대 효과)를 요약한 것이다. 상세 화면 설명·플로우 구조는 [메인 README](../README.md) 참고.

## 1. 개발 목표

ESP32와 환경 센서, MQTT–Node-RED 기반 서버·대시보드를 연동해 **실제 가정 환경에서 활용 가능한 통합 스마트 홈 모니터링 및 수면 환경 분석 시스템**을 구현한다.

1. 실내 환경(온도·습도·조도·가스·소음·인체 감지)을 단일 ESP32 노드에서 수집 → MQTT 전송 → Node-RED 대시보드로 통합 모니터링.
2. 생활 상황에 따라 `HOME` / `AWAY` / `SLEEP` 모드로 동작을 구분하는 모드 기반 제어 구조.
3. 수면 모드에서 소음 데이터를 세션 단위로 기록·시각화 → 수면 품질 분석 기초 데이터 확보.
4. 기상청 API · 텔레그램 Bot API 연동으로 실사용에 가까운 스마트 홈 경험(실내·외부 통합 표시, 외출 중 침입·이상 소음 알림).
5. ESP32·MQTT·Node-RED·대시보드·외부 API 전 과정을 아우르는, 센서 추가·기능 확장이 쉬운 기반 시스템.

## 2. 기술 개요

- **하드웨어** — ESP32 + DHT11(온·습도), 조도(CDS), 가스, 마이크, PIR, LED, 부저. 실내 환경을 실시간 수집해 Wi-Fi 로 MQTT 브로커에 전송.
- **통신** — 센서값을 JSON 패킷으로 묶어 `home/sensors`, `home/alert`, `home/mode/SLEEP`, `home/mode/WAKE` 등으로 publish.
- **서버/응용** — Node-RED 로 MQTT 수신·가공. Function 노드에서 파싱, 모드 상태 관리, 수면 소음 이벤트 누적, 실내 쾌적도·불쾌지수 계산과 히스토리 관리.
- **시각화** — Node-RED Dashboard 기본 위젯 + `ui_template` + Chart.js 로 실내 환경 변화·불쾌지수·수면 소음 패턴을 시간축 그래프로 표현.
- **외부 연동** — 기상청 초단기실황 API(HTTP Request → XML 파싱)로 실외 기온·습도·강수·바람 카드. 텔레그램 Bot API 로 `AWAY` 모드 침입·이상 소음 실시간 알림.

## 3. 독창성 · 도전성

- **상태 기반 제어** — 동일 센서 구성을 `HOME`(쾌적도) / `AWAY`(침입·이상 소음) / `SLEEP`(수면 소음)으로 다르게 운용.
- **DB 없는 수면 세션 분석** — Node-RED 컨텍스트만으로 수면 세션 단위 데이터 관리, `SLEEP`/`WAKE` 와 연동해 히스토리 초기화·마감.
- **실사용 지향 알림 정책** — `awaySince`(외출 직후 유예), `intrusionActive`(반복 알림 억제) 같은 상태 플래그로 오알림·스팸 제어.
- **데이터 구조 + 인터랙티브 UI** — `indoorHistory`, `chartRange` 등 상태 설계와 차트 범위 선택 UI 결합.

## 4. 기대 효과

- 온·습도·조도·가스·소음·인체 감지를 통합 표시해 위험 요소 조기 인지.
- 생활 패턴(모드) 선택만으로 센서 운용·경보 정책이 달라지는 스마트 홈 환경.
- 수면 중 소음 이벤트를 시간축으로 시각화해 수면 방해 요인 파악.
- 동일 MQTT 토픽 체계 안에서 센서·노드 확장이 쉬워 주거 환경 전체로 발전 가능.
